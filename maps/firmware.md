# Карта дампа и LZMA-ресурсов

## Общая раскладка

- Файл: `x280_backup_16M.bin`, 16 MiB.
- Наблюдение: четыре 4-MiB участка побайтно одинаковы. Уникальные данные анализируются в первой копии (`0x000000–0x3FFFFF`).
- База ROM-указателей для найденных таблиц: `0x10000000`; файловое смещение получается вычитанием этой базы.

## LZMA-Alone

Маркер `5C 00 00 40` расположен в начале стандартного 13-байтового LZMA-Alone заголовка:

| Поле | Смещение | Значение/смысл |
|---|---:|---|
| Свойства LZMA | `+0` | `0x5C` (`lc=2, lp=0, pb=2`) |
| Словарь | `+1..+4` | LE32 `0x00400000` (4 MiB) |
| Размер результата | `+5..+12` | LE64, little-endian |
| Сжатые данные | `+13` | raw LZMA1 stream |

В первой 4-MiB копии найдено 57 точных маркеров: 55 блоков декодируются в объявленный размер, один имеет некорректные поля, один кандидат не декодируется. Не все маркеры являются валидными ресурсами.

## Каталог из 42 сжатых групп

- `0x10FA04`: LE32 count = 42.
- `0x10FA08..0x10FAAC`: 42 LE32 ROM pointers.
- Код содержит ссылки на count и базу массива около `0x85AA4`.
- Каждый указатель ведёт к четырёхбайтовой обёртке перед LZMA-Alone заголовком.
- Диапазон целевых LZMA-заголовков: `0x13D144..0x151C04`.
- Это каталог групп ресурсов, не доказанная таблица ID приложений.

Полная таблица: [`../data/resource-pointer-directory-42.json`](../data/resource-pointer-directory-42.json).

## Неизвестное

- Значение слова `0x167` после каталога (`0x10FAB0`) неизвестно.
- Полная схема всех блоков/обёрток не установлена.
- Контрольные суммы и правила приёма прошивки телефоном не определены.
